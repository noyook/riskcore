# 第一性原理重构摘要（一页版）

## 六条原子事实
1. 风险是三元关系：危险能量源 × 暴露 × 控制失效概率；缺一即坍缩。
2. 风险永远关于未来 → 一切风险值都是带误差棒的估计，不是测量。
3. 系统里唯一经济上真实发生的是动作。
4. 最小输入只有三类：证据、先验、决策时刻的谓词。
5. 最小算力 = 每事件个位数算术操作；架构付费全在信任/规模/审计。
6. 闭环反馈是把估计变成准确的唯一机制（校准器，不是功能）。

## 合并架构终稿
事件 → 事实日志（本体）→ 投影器（可丢弃缓存）→ 纯函数（r + confidence + explain）→ 执行器（滞后/fail-closed/覆写）→ 动作回流。
读侧：披露层（对人）、投影层（对监管），均不反驱内核。
验证：黄金重放 + 属性测试 + 对账 + 双跑。

## 真实瓶颈（诚实清单）
- 法律边界：监管要纸形真相 → 投影层是一等公民。
- 传感成本：拿证据的代价决定系统上限。
- 小样本：交互项过拟合 → 白名单制 + 披露标注。
- 社会信任：信任设计进证据披露，而非信号防抖。
- 可用性物理：fail-closed 与分区容忍的冲突转化为证据新鲜度。
