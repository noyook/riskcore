# 术语表

| 术语 | 定义 |
|---|---|
| 事实日志 Fact Log | 系统唯一本体；append-only 事件序列 |
| 事件 Event | 信封化的不可变记录，状态变更的唯一来源 |
| correction 链 | 只追加的纠错机制，原事件永久保留 |
| 水位线 watermark | 对象内已被决策消费的 seq 上界 |
| fact | 状态变量（原 KRI 的原子化），带新鲜度三态 |
| 纯函数 risk() | 无记忆确定性映射：快照+policy → r/confidence/explain |
| policy | 版本化参数文档（权重/阈值/条款号），函数不内嵌数字 |
| 否决性事件 veto | 强制条款载体，命中即 r=1000，跳过算分 |
| 交互项 | 因子间超线性叠加项，白名单制 |
| 先验注入 | 遥测缺失时用 LEC-D 基线兜底（T2 的承认） |
| 滞后带 hysteresis | 执行器内的上下界回滞，吸收阈值抖动 |
| fail-closed | 取不到 r 按最严干预处理 |
| stale_after | 状态有效期，过期即视为取不到 r |
| 谓词 predicate | 声明式干预规则（数据非代码），动作唯一出口 |
| explain | 决定性事件 ID 列表，披露层主菜 |
| confidence | {n_events, 窗口覆盖率, 新鲜度, 校准标注} |
| 人工覆写 | 一等事件，最高权重，置顶披露，到期自动失效 |
| 监管投影 | 同一日志+函数生成的监管语言产物，带版本钢印 |
| projection_only | 只供报告素材、不参与加权的事件类型 |
