# executor — 阈值执行器（全系统唯一动作出口）

> 区域契约：**只有这里能产出动作；未知即保守；每次干预必须给出条款号。**

## 本区域职责

1. 谓词声明库与求值引擎（predicates.md）。
2. 滞后带、fail-closed、stale_after、人工覆写的执行语义。

## 区域规则

1. 输入只有两个：实体的最新 RiskOutput（来自投影器缓存）+ 谓词声明。**绝不**调用纯函数、绝不查日志。
2. 滞后只加在"是否触发/解除动作"上，不回写 r；r 永远保持纯函数输出原样。
3. 强制条款命中（veto_active=true）→ 最高干预，无滞后豁免。
4. 取不到 r（缓存不可达/超时）→ 按谓词声明的 fallback 执行（默认 deny）。
5. 每个动作必须携带 clause（政策条款号）与 explain_refs，缺一项即拒绝执行。
6. 动作后果（锁车成功、工单创建）由调用方以事件形式回流日志——执行器自己不写日志。
