# disclosure — 证据披露层（对人的接口）

> 区域契约：**每条结论可下钻到事件；每次干预可出示理由；披露层不写内核。**

## 本区域职责

1. explain API 与证据链展示规范（explain-api.md）。
2. confidence 与"未经充分校准"标注的人类可读呈现。

## 区域规则

1. 披露层只读内核数据（日志 + RiskOutput + 谓词返回体），禁止任何写路径。
2. 一切面向人的数字必须带上下文：r 旁边必须有 confidence 与证据条数。
3. 人工覆写信息永远置顶，不得折叠隐藏。
4. 披露文本使用业务语言（"过去 30 天超速 5 次"），事件 ID / 条款号作为下钻入口。
