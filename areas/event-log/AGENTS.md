# event-log — 事实日志与状态库投影器

> 区域契约：**无事件，状态不变；日志只追加；快照永远可从日志重建。**

## 本区域职责

1. 事件信封与事件类型字典的唯一权威定义（event-schema.md）。
2. 日志写入规范：幂等、租户传播、correction 链、水位线语义。
3. 状态库投影器：fact 快照表 + 决策状态缓存 + 对账守护（projector.md）。

## 区域规则

1. 任何状态变更必须来自一个事件；禁止任何旁路写。
2. 日志表只允许 INSERT；UPDATE/DELETE 一律视为事故。
3. `seq` 由对象分区内的单调序列生成，禁止由调用方传入。
4. `correction` 事件不改变原事件，只追加；读取侧负责应用修正链。
5. `projection_only` 类型事件只为监管报告素材服务，**不参与** risk 加权。
6. 快照/缓存的构建与丢弃由本区域全权负责，其他区域只准读接口、不准绕开。
