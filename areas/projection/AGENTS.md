# projection — 监管投影层（纸形真相的生产线）

> 区域契约：**同一日志+函数，投影出监管语言；口径变更只动投影；产物带版本钢印。**

## 本区域职责

1. 监管产物定义与生成规范（projections.md）。
2. 版本钢印与重生成机制。

## 区域规则

1. 每份产物必须可重生成，且打印 function_version + policy_id + as_of 三件套。
2. 监管口径变更 = 改投影模板/映射，**禁止**为此改内核 schema 或函数。
3. 报告需要而内核没有的字段 → 追加 projection_only 事件（不参与加权）或改模板，二选一，走 DECISIONS 审批。
4. 投影层只读；重生成是幂等操作。
