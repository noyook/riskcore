# 测试计划

## 1. 黄金重放（Golden Replay）

- 对抽样对象固定 `(object_id, as_of, policy_id)`，两次运行输出逐比特一致（JSON 规范化后 diff 为空）。
- 每次 policy 发版、函数代码变更后全量重跑。
- 定期（周）对随机样本重放，防环境漂移。

## 2. 属性测试（Property-Based）

| 不变量 | 断言 |
|---|---|
| 无否决 | 快照无 veto_types 事件 → r_milli < 1000 |
| 否决优先 | 存在否决事件 → veto_active=true 且跳过后续所有步骤 |
| 单调映射 | 单个危险 fact 恶化（其他不变）→ r 不下降 |
| 迟滞在决策层 | r 在回滞带内波动 → 谓词输出不变 |
| correction | 更正后输出与"原事件未发生"逐比特一致（provenance 除外） |
| 饱和 | 任意事件风暴 → r_milli 恒 ∈ [0, 1000] |
| 覆写衰减 | override 到期后输出恢复纯函数值 |

随机事件序列生成器：按事件类型字典加权随机，长度 1–10^4，跑夜间全量。

## 3. 对账检查

- 投影器对账守护的漂移告警必须接入值班；漂移率 > 0 即失败。

## 4. 双跑影子（Shadow）

- 与现行系统并行，逐对象比对等级；目标：差异全部可解释。
- 产出：每日比对报告（一致率、差异分类、裁决记录）。
- 差异裁决原则：解释得清的记 DECISIONS；解释不清的是 bug，修函数，不补规则。

## 5. 投影一致性

- 三件套监管产物重生成后与上一版本 diff，非口径变更导致的差异 = 失败。
